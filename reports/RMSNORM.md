# RMSNorm 算法回移：功能正确与值得采用分别验收

本实验讨论9月30日公开组件中的 RMSNorm 设计向910B4的受限回移。新组件后端不能仅修改目标架构即视为兼容旧设备。当前 CANN 8.3 RC1 的直接探针缺少 `c_api/asc_simd.h`；旧 AscendC 向量后端则能编译执行。该结果限定当前 SDK，不证明未来 SDK 或独立后端不可行。

采用 FP32 归约、32 KiB 输入 tile 与权重复用，使用旧向量 API 重新实现。范围仅为连续 FP32、D128/2048、前向与输入梯度，权重冻结；不包含量化、residual、非连续 stride、weight gradient 或新硬件多阶段流水线。原始回移源码属于非 LLaMA-Factory 研究工程，本仓库只公开结论与数值，不发布该代码或二进制。

## 数值修订

第一版仅采用低层 Rsqrt 初值，17/17检查失败；真实形状前向/输入梯度 relative L2 约1.10e-3/1.14e-3。全零输入前向为0看似正确，但 `dx=dy*w/sqrt(eps)` 的梯度仍直接暴露倒平方根误差。

公开上游采用更精细的倒平方根补偿，首版回移简化遗漏了它，不能归咎于上游。受限实现使用两次 Newton 修订：

```text
v = mean(x²) + eps
r ← r × (1.5 − 0.5 × v × r²)
```

理想初值相对误差为e时，一次修订误差为 `−1.5e²−0.5e³`；实际还受 FP32 舍入影响。该实现没有完整复刻高低位/FMA补偿。

原门禁保持 `atol=rtol=2e-4`、relative L2<1e-5，修订后17/17 FP32前向与输入梯度检查通过，最大相对L2分别7.78e-8/8.19e-8。BF16少量舍入分歧仍存在，不宣称全域位级一致或完整模型 Adam 等价。

## 对照 CANN 强参照

5个窗口，每窗口100调用、10 warmup，计时前后设备同步。F+B包含 autograd，权重冻结；FP32核心表不含最终 BF16 cast。三条路径共用 `TASK_QUEUE_ENABLE=0`，结果不能直接外推默认任务队列行为。

| 形状 | CANN F / 回移 F，μs | CANN F+B / 回移 F+B，μs |
|---|---:|---:|
| 17×128 | 11.93 / 9.35 | 63.69 / 76.01 |
| 1512×128 | 12.07 / 26.11 | 64.55 / 71.77 |
| 6292×128 | 11.90 / 71.87 | 72.64 / 169.86 |
| 17×2048 | 11.92 / 9.71 | 65.04 / 71.86 |
| 1512×2048 | 24.72 / 28.38 | 79.28 / 74.82 |
| 6292×2048 | 108.31 / 107.59 | 317.01 / 288.84 |
| 804×2048 | 16.18 / 17.55 | 74.63 / 80.36 |

实际 BF16 包装前向：展开式78.57μs、CANN25.33μs、回移25.72μs。回移相对展开式约3.05×，CANN也约3.10×。CANN窗口25.17–26.34μs与回移25.68–25.77μs重叠，不能将1.5%中位数差解释为显著。

部分宽矩阵 F+B 略快，但窄长矩阵退化。32 KiB tile 在D128时64行、D2048时4行，逐行 scalar/vector 交互和显式屏障是候选成本；现有 trace 没有逐指令 stall/流量，不能定量归因。

**结论：受限算法可回移并通过 FP32 算子门禁；尚未证明优于 CANN 强参照，不接入完整训练，也不计入28.4%端到端收益。**
